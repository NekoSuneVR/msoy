# mSOY Docker / GHCR

This repository now includes a container build for the Java mSOY server and its GWT web client.

## Published image

The GitHub Actions workflow publishes multi-architecture images to:

```text
ghcr.io/nekosunevr/msoy
```

Images are built for `linux/amd64` and `linux/arm64`. The default branch publishes `latest`, version tags publish their matching tag, and branch/SHA tags are also generated by the workflow.

## Quick start

Copy the example environment file and change the database password:

```bash
cp .env.example .env
docker compose pull
docker compose up -d
```

The default ports are:

- `8080/tcp` - HTTP / web UI
- `47624/tcp` - mSOY/Presents game connection
- `47623/tcp` - legacy socket policy service

The Compose stack starts PostgreSQL and waits for it to become healthy before starting mSOY. PostgreSQL 13 is intentionally used with MD5 password authentication for compatibility with mSOY's old JDBC driver.

## Build locally

For the default localhost development image:

```bash
docker build -t msoy:local .
```

For a custom hostname, the legacy GWT client must be compiled with the public URL and server hostname because these values are embedded during the GWT build:

```bash
docker build \
  --build-arg MSOY_PUBLIC_URL=http://msoy.example.com/ \
  --build-arg MSOY_SERVER_HOST=msoy.example.com \
  --build-arg MSOY_BILLING_URL=http://msoy.example.com/billing/ \
  -t msoy:custom .
```

The historical Ant templates only understand `http://` while extracting build-time hostnames. HTTPS should therefore be terminated by a reverse proxy until that old template logic is modernized; do not blindly pass an `https://` build URL and assume every legacy client path supports it.

Runtime values can still be set with environment variables, but changing them cannot rewrite values already compiled into the GWT JavaScript.

## Main environment variables

| Variable | Default | Purpose |
| --- | --- | --- |
| `MSOY_PUBLIC_URL` | `http://localhost:8080/` | Public base URL; must end in `/` (the scripts normalize it) |
| `MSOY_SERVER_HOST` | `localhost` | Client/server hostname |
| `MSOY_HTTP_PORT` | `8080` | HTTP listener inside the container |
| `MSOY_SERVER_PORTS` | `47624` | Presents/game listener |
| `MSOY_SOCKET_POLICY_PORT` | `47623` | Legacy socket policy listener |
| `MSOY_DB_HOST` | `postgres` | PostgreSQL host |
| `MSOY_DB_PORT` | `5432` | PostgreSQL port |
| `MSOY_DB_NAME` | `msoy` | Database name |
| `MSOY_DB_USER` | `msoy` | Database user |
| `MSOY_DB_PASSWORD` | `msoy` | Database password; change this outside local development |
| `MSOY_JAVA_MEMORY` | `512M` | Server JVM maximum heap |
| `MSOY_JAVA_OPTS` | empty | Additional JVM options |
| `MSOY_CONFIG_DIR` | empty | Optional directory containing replacement server config files |

## Custom configuration

To provide your own complete configuration, mount a directory and point `MSOY_CONFIG_DIR` at it. Supported file names are:

```text
msoy-server.properties
msoy-server.conf
burl-server.properties
burl-server.conf
```

The entrypoint copies any supplied files into `dist/` and then appends the container runtime overrides.

## What this image builds

The container builds the Java server and GWT browser application. It intentionally does **not** make the normal image depend on the historical Flex 3/Flash client or native Thane VM. Those pieces are obsolete and are the main reason the original `ant distall` target is no longer a reproducible modern container build.

The missing `com.threerings:whirled-code:1.1-SNAPSHOT` dependency is repaired during the Docker build by checking out a pinned historical `greyhavens/whirled-api` revision and installing its Java API into the builder's local Maven repository.

## Legacy external integrations

Some optional features in this 2010s-era codebase refer to services that no longer exist or whose APIs have completely changed, including MochiAds and old Facebook REST/FQL-era integrations. The core Docker/server path does not require those integrations. They should remain disabled unless they are replaced with a compatible service rather than redirected to an unrelated endpoint.

The web bootstrap no longer loads the retired Google Analytics `ga.js`, the CSRF test no longer posts to the old public Whirled service, and the generated cross-domain policy no longer contains stale Whirled/DJWhirled host allowlists.
